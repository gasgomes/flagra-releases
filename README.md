# Flagra

O Flagra grava as suas partidas no Windows, acha os melhores momentos e monta shorts prontos para TikTok, Reels e YouTube. Tudo roda no seu PC: seus vídeos, sua câmera e o seu áudio nunca saem dele.

Este repositório guarda só os instaladores. O Flagra se atualiza sozinho a partir daqui.
